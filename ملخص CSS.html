II.لغة البرمجة CSS

1.طرق كتابة كود css

a/كتابة الكود داخل ملف html:

<style>
h1 {
 color: red;
 font-size: 50px;
 }
</style>

• ملاحظة:

° لتطبيق نفس الكود في عنصرين مختلفين نستخدم رمز , حيث:

h1 , h2 , p { color: blue; }

b/كتابة الكود في مسار ملف css خارجي:

<link rel="stylesheet" href="مسار ملف css">

c/كتابة الكود داخل وسم العنصر:

<h1 style="color:red; font-size:20px; font-weight:500"> العنوان </h1>

2.مصطلحات خاصة بلغة CSS

a/مصطلحات خاصة بالمحتوى:

  • content: المحتوى.
  • padding: مساحة داخلية تفصل المحتوى عن حدوده.
  • border: حدود أو سمك المحتوى.
  • margin: مساحة خارجية تحدد المحتوى الفاصل.
  • fit-content: التناسب مع المحتوى، مثلا:

    h1 { height: fit-content; }

  • max-content: ضبط حجم المحتوى ليناسب أقصى حجم طبيعي ويكتب في سطر واحد مهما يكن.
  • min-content: تقطيع المحتوى المكتوب إلى كلمات.
  • max-width: أقصى عرض ممكن.
  • min-width: أقل عرض ممكن.
  • max-height: أقصى طول ممكن.
  • min-height: أقل طول ممكن.

b/مصطلحات خاصة بـ:

c/مصطلحات عامة:

  • top: أعلى ،مثلا: border-top
  • bottom: أسفل ،مثلا: border-bottom.
  • left: يسار.
  • right: يمين.
  • background: خلفية العنصر.
  • class: تمييز عنصر أو عدة عناصر بواسطة (.) متبوعة بالرمز المشترك:

    ° <h1 class="abc">title</h1>
    ° css : .abc { }

  • * : أداة تسمح بتمييز جميع عناصر المتصفح والتعديل عليها.

3.أنواع العناصر المتحكمة بالمحتوى الخاصة بلغة CSS

a/الإطارات border:

• أنواع الإطارات border:

 1/ أنماط الحدود (border-style):

  • solid: خط صلب ومستمر.
  • dashed: خطوط متقطعة.
  • dotted: نقط متفرقة.
  • double: خط مزدوج.
  • hidden: مخفي.
  • none: لا يوجد حد.

 2/ أنماط ثلاثية الأبعاد (3D style):

  • groove: محفور في الصفحة ثلاثي الأبعاد.
  • ridge: بارز ثلاثي الأبعاد.
  • inset: المحتوى غائر داخل الإطار.
  • outset: إبراز المحتوى من الإطار.

 3/ تكوير زوايا الحدود للمحتوى (border-radius):

  • قيمة واحدة: تطبق على الزوايا الأربعة.
  • قيمتان: الأولى أعلى يسار وأسفل يمين ،الثانية الزوايا المعاكسة.
  • ثلاث قيم: الأولى أعلى يسار ،الثانية أعلى يمين وأسفل يسار ،الثالثة أسفل يمين.
  • أربع قيم: أعلى يسار ،أعلى يمين ،أسفل يمين ،أسفل يسار.
نستطيع التحكم في الخصائص الفردية لكل زاوية ،نأخذ زاوية أعلى يسار مثلا:

border-top-left-radius: 10px;

b/الخطوط font:

1/ نوع الخط font-family :

• عائلة الخطوط العامة في css:

  • serif: تحتوي على نتوءات أو حواف صغيرة في الأطراف.
  • sans-serif: خطوط بدون نتوءات.
  • monospace: جميع الحروف لها نفس العرض، وتستخدم غالبًا في عرض الأكواد البرمجية.
  • cursive: خطوط تشبه الكتابة اليدوية المتصلة.
  • fantasy: خطوط زخرفية أو مرحة.

• أنواع الخطوط التي تدعمها جميع أنظمة التشغيل:

يكتب نوع الخط الذي يحتوي على فواصل داخل علامة تنصيص فردية 'Times New Roman' ,أو داخل علامة تنصيص مزدوجة "Times New Roman".
  • Tahoma.
  • Times New Roman.
  • Georgia.
  • Arial.
  • Verdana.
  • Helvetica.
  • Courier New.
  • Lucida Console.
  • Monaco.
  • Brush Script MT.
  • Lucida Handwriting.
  • Copperplate.
  • Papyrus.

2/ نمط الخط font-style:

  • normal: القيمة الافتراضية.
  • italic: الخط مائل.
  • oblique: الخط مائل بشكل بسيط.

3/ سمك الخط font-weight:

  • 100: نحيف جدا.
  • 200: خفيف جدا.
  • 300: خفيف.
  • 400: عادي.
  • 500: متوسط.
  • 600: شبه غامق.
  • 700: غامق.
  • 800: غامق جدا.
  • 900: أسود ثقيل.

4/ حجم الخط font-size:

• يقدر حجم الخط بـ px ,وحجمه الإفتراضي في معظم الصفحات 16px.
• لتكيف حجم الخط بسلاسة بين حد أدنى وحد أقصى أثناء تغير حجم الشاشة نستخدم وظيفة ()clamp, كمثال:

font-size: clamp(16px, 2vw, 32px);

4.أمثلة حول تطبيق بعض أكواد البرمجة CSS

a/صندوق المحتوى(margin,border,padding):

• مثال:

h1 {
 border: solid 1px red;
 padding: 20px 10px;
 margin: 15px 10px 30px;
 height: 200px;
 width: 100px;
 }

• ملاحظة:

هناك طريقتين للتحكم في قيم خصائص المحتوى.

  1/الخصائص الفردية:

• border-top: التحكم في قيمة الجزء العلوي للمحتوى.
• border-right: التحكم في قيمة الجزء الأيمن للمحتوى.
• border-bottom: التحكم في قيمة الجزء السفلي للمحتوى.
• border-left: التحكم في قيمة الجزء الأيسر للمحتوى.

  2/الخاصية المختصرة:

• قيمة واحدة: تطبق على الجوانب الأربعة. مثلا:

padding: 15px;

• قيمتان: الأولى للعلوي والسفلي ،الثانية للأيمن والأيسر. مثلا:

margin: 10px 15px;

• ثلاث قيم: الأولى للعلوي ،الثانية للأيمن والأيسر ،الثالثة للسفلي. مثلا:

margin: 15px 20px 10px;

• أربع قيم: العلوي ،الأيمن ،السفلي ،الأيسر بالترتيب. مثلا:

margin: 10px 10px 0px 30px;
